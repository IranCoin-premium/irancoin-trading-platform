# IranCoin Premium Trading Platform

Premium dark-first trading platform with 20 master prompts, built with Stitch + React/Next.js

- **Stitch Project:** `projects/13472457734608405708` — https://stitch.withgoogle.com/projects/13472457734608405708
- **Live Demo:** See Deployment section
- **Source Prompts:** https://github.com/IranCoin-premium/prompts (20 parts, 5260 lines Part1 etc)
- **Design System:** Aureus Intelligence — dark #0A0A0B charcoal, gold #D4AF37, blue #0EA5E9, glass blur, Inter + Vazirmatn, RTL/LTR, WCAG 2.2 AA
- **Stack:** Next.js 14, React 18, Tailwind CSS, TypeScript
- **Mode:** Web / DESKTOP (as requested) — App (React Native) can be generated with same prompts + deviceType MOBILE

## Quick Start
```bash
npm install
npm run dev
# http://localhost:3000
# /part1 ... /part20 , /review
```
